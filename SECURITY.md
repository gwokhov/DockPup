# Security

DockPup runs with Accessibility access so it can inspect the Dock and modify
mouse events. Treat permission handling and input behavior as security-sensitive.

## Reporting a vulnerability

Use **Security → Report a vulnerability** on GitHub when private vulnerability
reporting is enabled for this repository. If that option is unavailable, open a
brief issue requesting a private contact channel without including exploit
details or personal data.

Include the affected revision, macOS version, reproduction steps, and expected
impact. Redact usernames, file paths, tokens, and unrelated logs.

Security fixes target the current development version. There is no guaranteed
response time or long-term support policy for older revisions.
